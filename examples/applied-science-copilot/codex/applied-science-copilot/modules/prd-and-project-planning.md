# PRD and Project Planning

Use this module to convert vague ideas into executable AI product work.

## PRD workflow

1. Identify users, jobs-to-be-done, workflow moments, and current baseline.
2. State non-goals and autonomy boundaries.
3. Define success metrics and unacceptable failures.
4. Create a capability decision: process/template/search/RAG/tool/skill/agent/training.
5. Convert into milestones and tickets.

## PRD artifact

Produce:

- Problem statement
- User/workflow map
- Jobs to improve
- Non-goals
- Autonomy level now / later
- Required context/data/tools
- Metrics and guardrails
- Baseline ladder
- MVP scope
- Risks and dependencies

## Project plan artifact

Produce:

- Workstreams: product, data, retrieval/context, model/prompt, agent/tools, evals, infra, observability, governance
- Milestones with exit criteria
- Tickets with acceptance criteria
- Decision log
- Risks and mitigations
- First two-week execution plan
