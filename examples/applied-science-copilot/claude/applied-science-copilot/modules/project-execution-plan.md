# Project Execution Plan

Use this module to turn a PRD or research/product idea into executable work.

## Workstreams

- Product/UX
- Data and labeling
- Retrieval/context or features
- Model/prompt/training
- Agent/tools/runtime
- Evaluation and experimentation
- Serving/platform
- Observability and cost
- Security/governance
- Release/rollout

## Planning workflow

1. Break the project into milestones with exit criteria.
2. Identify dependencies and critical path.
3. Convert milestones into tickets with acceptance criteria.
4. Define artifacts required for each stage.
5. Add validation commands/evals for each implementation slice.
6. Define risk burndown plan.

## Outputs

- Milestone plan
- Ticket backlog
- Dependency map
- Staffing/ownership assumptions
- Risk register
- First two-week execution plan
