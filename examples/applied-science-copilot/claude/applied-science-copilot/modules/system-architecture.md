# System Architecture

Use this module for RAG, agent, tool, memory, model serving, and product architecture.

## Architecture surfaces

- Product workflow and user journey
- Context contract and source policy
- Retrieval/indexing/reranking/context packing
- Prompt/model routing
- Tool registry and tool contracts
- Skill library and skill router
- Agent runtime state machine
- Memory policy
- Evals, traces, dashboards, and release gates
- Security/governance controls

## Required outputs

- System diagram or textual architecture
- Component contracts
- Data/control flow
- Failure modes
- Build plan
- Eval plan
- Observability plan
- Launch gate
