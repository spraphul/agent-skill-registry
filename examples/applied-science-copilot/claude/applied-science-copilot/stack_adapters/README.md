# Stack Adapters

Use these as lightweight routing notes. Before implementation, fetch current official docs for the selected stack.

Initial adapter targets for future iterations:

- DSPy: signatures/modules and optimizers such as BootstrapFewShot, MIPROv2, GEPA.
- LangChain/LangGraph: agent graphs, tools, persistence, LangSmith tracing/evals.
- LlamaIndex: data connectors, indexing, retrieval, query engines.
- OpenAI/Anthropic APIs: model calls, tool use, structured outputs, evals, batch jobs.
- RAGAS/DeepEval/Braintrust/Phoenix/Langfuse/LangSmith: eval and observability.
- Optuna/Ax/Nevergrad/Ray Tune: search and Pareto optimization.
